    What to probe

    Items that already have media info are always skipped. Turn off "Only .strm items" to also probe regular files that are missing it.

    Pace

    Each probe opens one stream. Keep this below your provider's connection limit, minus what you need for watching. 1 is safest.
    A probe that hasn't answered by then is stopped (its connection is closed) and the item is marked as timed out.
    Gives the provider a moment between streams.
    Sent with each probe. Some providers only accept known players.

    Limits

    Handy for a nightly window: the next run carries on where this one stopped.
    Usually means the provider is down or refusing connections; no point hammering it.

    Extras

    Within a couple of minutes of a scan adding items to a selected library. Uses the same pace settings.
    To run on a schedule, add a trigger to "Extract media info (strminfo)" under Scheduled Tasks.
